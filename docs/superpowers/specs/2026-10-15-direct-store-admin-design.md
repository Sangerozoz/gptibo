# 直营主站与管理台设计

**日期：** 2026-10-15
**状态：** 交互设计已获确认；等待用户审阅本规格
**当前验收环境：** 本地 Cloudflare Worker、D1 和 `http://127.0.0.1:8788/`

## 目标与边界

经营模式改为平台直营。`/` 是唯一对外经营的主站，`/admin` 是站长管理台。保留已有代理工作台、代理数据表和结算逻辑，以便以后重新开放；当前默认关闭代理入口和新代理开通能力，主站不得通过一个虚构的代理账号运行。

第一期让站长在后台管理店铺品牌、商品分类及**已有商品**的展示内容、顺序和上下架。后台已有的套餐售价编辑继续使用。不新增任意商品、任意套餐或新交付方式；这些属于下一期。商品原有 ID、订单、支付、发货和售后记录保持有效。

## 已确认的使用规则

- 中文站名默认「硅基生物」，英文站名默认「MEGHAN」。两种语言只显示对应名称；英文内容未填时回退中文。
- 店铺设置可更换 Logo。没有上传新 Logo 时，继续使用现有品牌图形。
- 分类可新增、改名、排序、停用，商品可重新归类。固定的「全部商品」不是可删除的分类。停用分类只移除筛选入口；其商品仍在「全部商品」中显示，不会被连带下架。
- 现有商品可编辑中英文名称、简介、图片和所属分类，并可排序、上架、下架。未上传商品图片时保留现在的专属插画。编辑内容用于列表和适用的详情页；套餐价格由现有「商品与套餐」入口修改。
- 商品下架后，前台不展示卡片，直接访问详情提示已下架，服务端拒绝该商品的新订单；已有订单仍可查询和处理。商品上架不自动启用被暂停的套餐或未配置的供应商服务。
- 当前对外站点不显示代理招募或代理工作台入口。代理模式通过配置开关重新启用，关闭状态不删除代理数据、历史订单或代码。

## 方案选择

采用**为直营主站增加独立配置**。已有套餐和交易模型继续承担定价、订单及交付；直营展示数据单独管理。没有采用「把主站伪装成代理店」，因为代理定价、佣金和结算会进入直营订单；也没有另建商城，以免复制现有支付、订单和售后系统。

## 页面与数据流

管理台新增三个页面：

1. **店铺设置：** 中文名称、英文名称、Logo 和预览。中文名称必填；英文名称可空并回退中文。页面标题和前台页头、页脚使用同一份设置。现有邮件的品牌文字与图形也应读取同一份平台设置；邮件发件地址仍由部署配置控制。
2. **分类管理：** 显示名称（中英文）、顺序、启用状态及归属商品数。分类内部 ID 创建后不可改；停用分类时明确提示商品仍留在「全部商品」。
3. **商品管理：** 固定列出仓库已支持的商品 ID，包括待上架商品。可编辑中英文名称、短简介、分类和图片；可拖动排序并切换展示状态；套餐售价链接到现有编辑界面。商品 ID、交付类型、供应商映射和订单关系不可在此修改。

公开目录接口返回品牌、分类和商品展示配置。前台以后台配置覆盖当前写在代码里的展示文案；缺失配置时使用现有默认值，所以初次迁移不改变正在展示的页面。商品画面保留现有专属组件，上传图片才覆盖画面。公开接口只返回展示所需字段，不返回管理版本、审计备注或内部配置。

目录之外，创建订单的服务端路径再次核对直营商品状态，防止用户绕开前台直接提交已下架商品。商品状态与套餐 `enabled` 分开：前者控制整个商品是否展示和能否下单，后者控制具体套餐是否可购买。

## 存储与接口约束

- 为直营站建立单例店铺设置、分类表和以现有商品 ID 为键的展示配置表。对已有商品写入初始配置或在读取时回退现有常量；迁移不得改写订单及代理表。
- 图片上传只接受经过解码校验并压缩的图片，限制尺寸和体积；公开目录返回媒体 URL，避免把大块图片数据塞进目录响应。未上传图片用现有静态资源。上传失败不得改变已保存图片。
- 管理写接口复用现有管理员会话和同源请求防护；所有更改校验输入、版本号并记录审计。版本冲突返回可刷新重试的提示，不静默覆盖别人的编辑。
- 分类名和顺序、商品顺序由服务端校验。已被停用的分类仍可被商品引用，以保留归类关系；公开筛选只列启用分类。
- `PARTNER_MODE_ENABLED` 默认关闭。关闭时隐藏管理台中的代理专用入口，阻止新代理开通、代理登录及代理商店访问；保留历史数据和直营订单查询。重新开启时沿用原代理逻辑，不要求数据迁移。

## 后端范围

当前运行和第一轮交互验收基于 Worker/D1。前端接口形状不绑定 Worker，以便 Go/PostgreSQL 后端实现同一合同。如果以后选 Go 作为正式站点后端，必须先补齐相同的设置、目录和订单拦截接口并通过验收；不能把 Worker 本地通过视作 Go 部署就绪。服务器与域名信息尚未提供，本规格不包含正式部署。

## 验收标准

- 管理员能更新主站中英文名称和 Logo，切换语言后只出现该语言的名称；英文留空时回退中文，当前默认品牌在未保存配置时保持原样。
- 管理员能新增、改名、排序、停用分类并调整现有商品归类；停用分类后商品仍在「全部商品」。
- 管理员能修改现有商品名称、简介和图片、调整顺序及上下架；前台列表与详情一致，未上传图片仍显示原画面。
- 下架商品的直接订单请求被服务端拒绝；已有订单、售后和历史记录仍可访问。重新上架不自动改变套餐销售状态。
- 代理模式关闭时没有可用的代理登录、开通或代理商店入口；代理相关数据与代码未删除。
- 覆盖管理权限、非法输入、并发版本冲突、中英文回退、商品可见性及直接下单绕过的测试；构建和相关现有回归测试通过，并在桌面及窄屏检查前台布局。
